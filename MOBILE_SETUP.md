# Put the App on an iPhone

## 1. Publish with GitHub Pages

1. Open the GitHub repository.
2. Click `Settings`.
3. Click `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Under `Branch`, choose:

```text
main
```

6. Under folder, choose:

```text
/ root
```

7. Click `Save`.
8. Wait a few minutes.
9. GitHub will show a website link like:

```text
https://your-name.github.io/brixham-swim-forecast/
```

## 2. Add to iPhone Home Screen

1. On your iPhone, open `Safari`.
2. Go to the GitHub Pages link.
3. Tap the share button.
4. Tap `Add to Home Screen`.
5. Name it:

```text
Brixham Swim
```

6. Tap `Add`.

The app icon should now appear on your iPhone Home Screen.

## 3. Updating the App Later

When files are changed:

1. Upload the changed files to GitHub.
2. Wait a few minutes for GitHub Pages to update.
3. Open the app on your iPhone.
4. If it still shows the old version, fully close it and reopen it.
